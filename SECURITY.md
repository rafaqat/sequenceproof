# Security policy

Do not report vulnerabilities in public issues. Use the repository's
[private vulnerability report](https://github.com/rafaqat/sequenceproof/security/advisories/new),
which is enabled and verified for confidential intake. Include affected versions, reproduction
steps, impact, and any suggested mitigation. Maintainers will coordinate disclosure through a GitHub
Security Advisory.

The SequenceProof Engine is privileged test infrastructure and must never be enabled in production.
Neither package has been published yet; registry publication remains blocked on ownership, legal,
and trusted-publishing checks.
